# Personal Skills

Locally maintained Skills that are being consolidated into this repository. They are linked by the maintainer script but are not shipped in the current plugin.

- **[add-dir](./add-dir/SKILL.md)**: Add a directory to the current Codex working context and persist it for the project.
- **[agent-rules](./agent-rules/SKILL.md)**: Route coding, workflow, review, testing, TypeScript, and Git tasks to Shay's focused standards.
- **[commit](./commit/SKILL.md)**: Create scoped local commits while excluding unrelated, ignored, disposable, or sensitive files.
- **[git-workflow-standards](./git-workflow-standards/SKILL.md)**: Apply Shay's Git, deletion, merge-conflict, and worktree safety rules.
- **[personal-coding-standards](./personal-coding-standards/SKILL.md)**: Apply Shay's cross-language coding and refactoring conventions.
- **[personal-development-workflow](./personal-development-workflow/SKILL.md)**: Apply Shay's research, planning, implementation, review, and verification workflow.
- **[review-standards](./review-standards/SKILL.md)**: Apply Shay's severity, evidence, and findings format for code review.
- **[testing-standards](./testing-standards/SKILL.md)**: Apply Shay's risk-based testing, TDD, and PHP/PHPUnit conventions.
- **[typescript-standards](./typescript-standards/SKILL.md)**: Apply Shay's TypeScript and JavaScript type, validation, logging, and testing conventions.
- **[worktree-clean](./worktree-clean/SKILL.md)**: Audit and safely remove unused agent worktrees for the current repository.
